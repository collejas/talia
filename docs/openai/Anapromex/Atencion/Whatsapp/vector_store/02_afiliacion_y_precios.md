# Afiliación, requisitos y precios de referencia

## Requisitos generales

- Documento del vehículo: título, factura, pedimento u otro aceptado.
- INE vigente.
- Dos fotografías tamaño infantil.

La sucursal debe confirmar documentación adicional y elegibilidad.
