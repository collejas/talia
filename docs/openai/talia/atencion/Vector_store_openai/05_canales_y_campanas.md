# Canales y campañas

## Atención

Tal-IA atiende conversaciones por WhatsApp y Webchat según la configuración del tenant.

## WhatsApp

La plataforma puede recibir y responder mensajes por WhatsApp mediante el proveedor configurado. Las plantillas, ventanas de atención y reglas del proveedor pueden limitar algunos envíos.

## Webchat

El agente puede atender visitantes desde el Webchat e intercambiar información con el CRM según la configuración disponible.

## Campañas

La plataforma permite preparar y ejecutar envíos masivos de WhatsApp mediante la API de WhatsApp y de correo.

La existencia de una campaña no significa que un contacto haya recibido un mensaje. Solo confirmar un envío cuando el sistema o la herramienta lo reporte como exitoso.

## Prospección relacionada

La plataforma puede obtener contactos mediante Google y bases empresariales mexicanas antes de preparar campañas. La búsqueda de contactos, el envío de campañas y la atención IA son procesos distintos.
