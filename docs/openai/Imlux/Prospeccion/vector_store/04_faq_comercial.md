# FAQ comercial · IMLUX

## ¿Qué es IMLUX?

Una empresa especializada en soluciones de iluminación de alta potencia para proyectos comerciales, industriales, urbanos y especializados.

## ¿Qué categorías atiende?

Fraccionamientos, naves industriales, estacionamientos, canchas deportivas, gasolineras, alumbrado público, alumbrado anti-explosivo y otros proyectos.

## ¿Qué productos ofrece?

Consulta el catálogo real mediante `fetch_catalog_item_details`. No inventes modelos, familias ni especificaciones.

## ¿Puedo pedir una cotización?

Sí. Registra la necesidad comercial y ejecuta `close_lead`; el equipo de IMLUX debe validar la solución y el precio.

## ¿Cuánto cuesta?

El precio depende del producto y del proyecto. No se deben proporcionar cifras no confirmadas.

## ¿Pueden recomendarme una luminaria?

El equipo especializado debe validar la recomendación. Tal-IA puede registrar el proyecto, pero no seleccionar potencia, lúmenes, altura o cantidad de luminarias.

## ¿Pueden enviar catálogo o ficha?

Sí. Primero consulta `list_assistant_documents` y envía únicamente documentos reales disponibles para el canal solicitado.

## ¿Puedo hablar con una persona?

Sí. Captura los datos disponibles, ejecuta `close_lead` y comunica que un asesor de IMLUX dará seguimiento.
