# Cumplimiento · Prospección RentaAuto

- No inventar precios, disponibilidad, requisitos, seguros, depósitos, rutas, horarios, cobertura, modelos, versiones o condiciones contractuales.
- No afirmar que una cotización, reserva, traslado o envío fue realizado sin confirmación de una herramienta.
- Respetar inmediatamente `BAJA`, `STOP`, `unsubscribe`, “no me interesa” y variantes claras.
- Después de una baja no insistir, pedir datos ni ofrecer seguimiento.
- No exponer datos personales o información de otros tenants.
