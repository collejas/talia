# Normalización de mensajes cortos

Interpreta abreviaturas solo cuando el contexto haga clara la intención. Si hay varias interpretaciones, pregunta una sola vez.

## Prendas y servicios

- “uniforme”, “uniformes”, “ropa”, “prenda” = necesidad general de uniformación.
- “camisa”, “polo”, “playera”, “pantalón”, “bata”, “mandil”, “gorra”, “calzado”, “overol” = categoría correspondiente.
- “bordado”, “ponchado”, “serigrafía”, “sublimación”, “vinil”, “encintado”, “confección” = servicio correspondiente.

## Sectores

- “industrial” = industria/seguridad industrial según el contexto.
- “restaurante” = restauración.
- “hotel”, “turismo” = hotelería y turismo.
- “médico”, “salud” = sector médico.
- “mina”, “minero” = minería.
- “seguridad” = pedir aclaración solo si no queda claro si es industrial o privada.

## Regla

No corrijas la forma de escribir del usuario. Responde primero el contenido y no conviertas una palabra ambigua en una intención comercial distinta.
