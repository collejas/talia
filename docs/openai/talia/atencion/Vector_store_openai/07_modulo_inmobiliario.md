# Módulo inmobiliario de Tal-IA

Tal-IA cuenta con una edición inmobiliaria para desarrolladoras, inmobiliarias y negocios de bienes raíces.

## Qué administra

- Desarrollos inmobiliarios con tipo, ubicación, status y geometría principal.
- Niveles, capas, macrolotes y manzanas relacionados con el desarrollo.
- Unidades o propiedades con tipo, área, precio, precio por metro cuadrado, destino de inventario y estado comercial.
- Mapa comercial para revisar ubicación, límites y cobertura del inventario.
- Relación entre una unidad, una oportunidad, una cotización y el estado comercial de la venta.
- Agenda de visitas, demos y seguimiento comercial.

La edición inmobiliaria publicada también contempla visualización de propiedades en 3D. La disponibilidad de esa visualización y sus elementos depende de la configuración y del inventario cargado por cada organización.

## Atención con inventario

Cuando el usuario pregunte por un desarrollo, fraccionamiento, modelo, unidad, precio, disponibilidad, ubicación o estado comercial, la respuesta debe basarse en el catálogo inmobiliario vigente del tenant mediante la herramienta disponible.

No inventar nombres, precios, áreas, ubicaciones, disponibilidad, estados ni características de unidades. Si el catálogo no está habilitado, no tiene resultados o la herramienta no confirma el dato, indicar que no se cuenta con esa información y ofrecer una demo o contacto comercial si el usuario lo solicita.

El catálogo inmobiliario es distinto del catálogo general de productos y servicios. No mezclar ambos.

## Respuestas breves

Si preguntan qué hace el módulo, mencionar solo lo necesario: organiza desarrollos, niveles y unidades; muestra inventario y mapa comercial; y vincula el seguimiento con oportunidades y ventas.

Si preguntan por una propiedad concreta, primero consultar el inventario real. No responder con información genérica cuando el usuario pidió una unidad o desarrollo específico.

Si preguntan por el precio del sistema, usar el documento de precios. Si preguntan por el precio de una propiedad, consultar el catálogo inmobiliario y aclarar que es el precio vigente devuelto por el sistema.
