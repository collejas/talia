# Normalización de mensajes cortos

- “afiliar”, “afiliación”, “registro” = afiliación nueva.
- “amparo”, “defensa”, “me quieren quitar el carro” = amparo o atención jurídica; si hay retención, tratar como urgente.
- “seguro”, “póliza”, “responsabilidad civil” = seguro.
- “lámina”, “engomado”, “calca” = identificación vehicular o canje de engomado.
- “cambio de dueño”, “pasarlo a mi nombre” = cambio de propietario.
- “renovar”, “credencial vencida” = renovación/actualización.

Si una palabra tiene más de un significado, pregunta una sola vez. No corrijas la forma de escribir del usuario ni asumas elegibilidad.
