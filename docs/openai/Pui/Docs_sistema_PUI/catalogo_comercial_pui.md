## 4) Reglas comerciales

- Todos los precios son mas IVA.
- Las primeras 30 instituciones tienen tarifa preferencial durante la etapa inicial.
- El Plan Manual implica carga manual de registros.
- El Plan Integracion Automatica implica integracion con sistemas del cliente.
- No prometer alcance extra si no esta escrito en este documento.
