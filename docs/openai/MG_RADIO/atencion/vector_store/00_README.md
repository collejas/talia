# Vector Store · Atención MG Radio WhatsApp

Nombre sugerido en OpenAI: `mg_radio_atencion_vs`

Este paquete está optimizado para:

- conversación breve de atención comercial,
- identificación de necesidad,
- manejo de objeciones,
- cierre a cita comercial.

## Archivos

- `01_propuesta_valor_por_industria.md`
- `02_objeciones_y_respuestas.md`
- `03_cierre_demo.md`
- `04_faq_comercial.md`
- `05_compliance_prospeccion.md`
- `06_normalizacion_inteligente_de_canales.md`

## Carga recomendada

1. Crear vector store nuevo (`mg_radio_atencion_vs`).
2. Subir estos 6 archivos.
3. Vincularlo al assistant de atención de MG Radio.
4. Validar respuestas:
   - breves,
   - 1 pregunta por turno,
   - enfoque en necesidad, datos mínimos y siguiente paso.
