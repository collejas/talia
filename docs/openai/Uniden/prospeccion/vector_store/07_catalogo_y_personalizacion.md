# Catálogo y personalización · UNIDEL

El sitio público organiza categorías para hombres, mujeres y accesorios, como pantalones, camisas, polos, playeras, calzado, chamarras, sudaderas, chalecos, filipinas, batas, trajes quirúrgicos, overoles, gorras y otras prendas.

Entre las marcas visibles o registradas en el catálogo se encuentran Dickies, Red Kap, Levi’s, Dockers, Gildan, Yazbek, Unitam, Workwear y otras. La lista activa puede cambiar.

## Personalización

UNIDEL confirma bordado, ponchado/digitalización, serigrafía, sublimación, vinil textil, encintado, diseño gráfico, ajustes, entallado y confección a la medida.

## Consulta obligatoria

Para responder sobre una referencia concreta, consulta el catálogo operativo: precio, existencia, talla, color, marca y especificaciones pueden cambiar. Si el catálogo no confirma el dato, informa el límite y deriva a cotización. No uses esta base como inventario ni publiques credenciales, URLs internas o datos de margen.
