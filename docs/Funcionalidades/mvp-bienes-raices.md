# MVP para empresas de bienes raíces

Este documento describe la versión mínima viable pensada para desarrolladoras o brokerages que venden propiedades. Integra el MVP general de TalIA con funciones clave específicas del sector inmobiliario para acompañar cada oportunidad desde la prospección hasta la firma.

## 1. Qué problemas resuelve para el sector
- Las consultas llegan por muchos canales y el equipo necesita una vista única para responder sin perder el contexto.
- los datos de los prospectos no estan centralizados en una base de datos.
- El inventario de propiedades no siempre se refleja en tiempo real; hay poco control sobre qué unidades están libres, reservadas o vendidas.
- El seguimiento documental de un comprador (identificaciones, comprobantes, contratos) es manual y se interrumpe si el cliente no sabe qué faltó.
- Las campañas de prospección no están centralizadas y se pierden oportunidades por falta de automatización.

## 2. Qué se entrega en esta versión
1. **Atención multicanal y captura de leads**  
   - Mensajes automáticos desde webchat, WhatsApp e email.  
   - Registro de nombre, correo, teléfono y necesidad sin que el cliente lo repita.  
2. **Panel visual del inventario con vista tipo plano 3D**  
   - El catálogo muestra bloques/flores de unidades con colores por estado (libre, reservado, vendido).  
   - Cada unidad ofrece accesos rápidos para “vender”, “reservar” o “apartado” y muestra fotos, métricas de visitas y notas del lead.  
3. **Roles y control de acceso**  
   - Administradores, gerentes y vendedores tienen vistas distintas.  
   - Los permisos ocultan datos sensibles (financieros, documentos) cuando no corresponde y permiten saber quién hizo cada acción.  
4. **Asistente documental para clientes listos para comprar**  
   - TalIA guía al cliente para subir identificaciones, comprobantes y contratos dentro del chat.  
   - El sistema valida formatos básicos, marca el avance y envía recordatorios si falta algo.  
5. **Automatización de campañas y prospección en frío**  
   - Plantillas de correo y WhatsApp con variables (nombre, propiedad, estado) para enviar a listas segmentadas.  
   - La campaña registra aperturas, clics y responde automáticamente con próximos pasos si alguien muestra interés.  
6. **Seguimiento de embudos y tareas accionables**  
   - Cada acción “reservar/apartar” genera tareas para el equipo comercial (visitas, cotizaciones, firma).  
   - El panel muestra la etapa del lead (contacto, visita, negociación, documento completado, venta) y qué falta para avanzar.

## 3. Cómo se mide el éxito
- Incremento en leads con datos completos gracias al asistente (~30%).  
- Reducción en el tiempo para cerrar una unidad (menos pasos manuales).  
- Más agendas confirmadas directamente desde el chat.  
- Menos documentos faltantes al momento de la firma.  
- Métricas de campaña (clics abiertos, respuestas) que alimentan la estrategia de marketing.

## 4. Próximos pasos a partir del MVP
- Añadir reportes financieros y de comisiones por unidad.  
- Integrar visitas virtuales o tours 360 dentro del inventario 3D.  
- Conectar con CRM externo o ERP contable para liberar contratos.  
- Seleccionar portales inmobiliarios para publicar automáticamente inventario, sincronizado con el estado interno.
