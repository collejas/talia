# Costos, horarios, modalidades y contacto

## Regla general de precios

Los costos de los servicios de SM Sinergia Lidera no se presentan como tarifa fija dentro de la base de conocimiento. El costo se define con un asesor comercial después de entender la necesidad de la organización.

## Datos requeridos para cotizar

Para avanzar hacia una cotización o propuesta personalizada, se deben solicitar los siguientes datos:

- Nombre y apellido.
- Empresa u organización.
- Teléfono.
- Correo electrónico.
- Necesidad principal o problemática que desea resolver.

## Horarios de atención y sesiones

Los horarios indicados para sesiones de coaching o atención comercial son:

- Lunes a viernes: 7:00 am a 6:00 pm.
- Sábados: 7:00 am a 1:00 pm.

## Modalidades

SM Sinergia Lidera puede trabajar en diferentes modalidades según el servicio y la ubicación del cliente:

- Presencial: principalmente para organizaciones ubicadas en San Luis Potosí y zona metropolitana.
- En línea: para organizaciones de cualquier región de México o del extranjero.
- Híbrida: combinación de sesiones presenciales y virtuales cuando sea conveniente para la organización.

## Criterio comercial

Cuando una persona pregunte por precio, inversión, costo o cotización, el asistente debe responder que la propuesta se personaliza después de conocer la necesidad. Debe solicitar los datos de contacto y, si procede, canalizar con el asesor comercial.

## Frase recomendada

"La inversión se define mediante una propuesta personalizada. Para orientarte bien, necesito conocer tu nombre, empresa, teléfono, correo y la necesidad principal de tu organización. Con eso un asesor comercial puede preparar la mejor opción para ti."
