# GEOACTIV UI/UX

Este skill guía el diseño de interfaces para GEOACTIV.

## Objetivo

Crear interfaces minimalistas, prácticas, lógicas, modernas y funcionales.

La UI debe ayudar al usuario a trabajar más rápido, entender mejor la información y tomar decisiones con menos fricción.

## Principios

* Minimalista.
* Práctica.
* Lógica.
* Funcional.
* Moderna.
* Clara.
* Rápida de usar.
* Enfocada en flujos reales de trabajo.

## Antes de diseñar una pantalla

Responder:

1. ¿Qué está viendo el usuario?
2. ¿Qué necesita resolver?
3. ¿Cuál es la acción principal?
4. ¿Qué información es prioritaria?
5. ¿Qué información puede quedar como secundaria?
6. ¿Qué debe pasar cuando no hay datos?
7. ¿Qué debe pasar si hay error?
8. ¿Qué debe pasar mientras carga?

## Evitar

* Pantallas saturadas.
* Formularios enormes sin secciones.
* Botones sin jerarquía visual.
* Modales innecesarios.
* Tablas ilegibles.
* Filtros inútiles.
* Acciones importantes escondidas.
* Componentes decorativos sin función.
* Interfaces bonitas pero lentas o confusas.

## Preferir

* Layouts limpios.
* Secciones claras.
* Acción principal visible.
* Acciones secundarias discretas.
* Buen manejo de estados: vacío, cargando, error, éxito.
* Formularios divididos por intención.
* Tablas fáciles de leer.
* Filtros útiles.
* Cards informativas cuando ayuden.
* Gráficas y mapas solo cuando aporten valor real.

## Stack visual

Usar de forma consistente:

* Next.js.
* React.
* TypeScript.
* Tailwind CSS.
* shadcn/ui.
* Radix UI.
* Recharts.
* Leaflet o Mapbox GL cuando aplique.

## Al entregar

Explicar:

* Estructura de la pantalla.
* Componentes creados o modificados.
* Flujo de usuario.
* Acción principal.
* Estados contemplados.
* Decisiones visuales importantes.
