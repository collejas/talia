# Vector Store · Atención Digitalenfa por WhatsApp

Nombre sugerido: `digitalenfa_atencion_whatsapp_vs`

Esta base contiene únicamente conocimiento factual y vigente para personas que escriben a Digitalenfa por WhatsApp. El comportamiento, el tono, la captura de datos, el uso de herramientas y las reglas de cierre viven en el prompt de WhatsApp y en la política dinámica del tenant.

## Archivos que se deben subir

- `01_empresa_y_servicios.md`
- `02_faq_atencion.md`
- `03_maquina_de_prospectos.md`
- `04_crm_kommo_y_automatizaciones.md`
- `05_canales_y_entregables.md`
- `06_limites_y_compliance.md`

No subir este README ni `whatsapp_funciones.md` como conocimiento factual.

## Reglas de mantenimiento

- Mantener solo información comprobable y vigente de Digitalenfa.
- No copiar precios de Tal-IA ni agregar precios mientras no exista una fuente aprobada.
- No incluir secretos, conversaciones reales, datos de otros tenants ni instrucciones internas.
- No incluir reglas de campos obligatorios de `close_lead`; se reciben de la política del tenant/canal.
- Las funciones se publican por separado.

## Publicación

1. Crear o conservar la vector store `digitalenfa_atencion_whatsapp_vs`.
2. Subir los seis archivos numerados.
3. Asociarla exclusivamente al prompt de atención de WhatsApp de Digitalenfa.
4. Probar preguntas sobre servicios, Máquina de Prospectos 24/7, IA/WhatsApp, CRM Kommo, precios no publicados, contacto, rechazo y baja.
