# Sucursales y atención jurídica

Para ubicar una sucursal se necesita estado y, si hace falta, municipio. Entregar únicamente dirección, teléfono y horario confirmados por la fuente oficial. No inventar ubicaciones.

Ante una retención, decomiso o solicitud de documentación: mantener la calma, no dar conclusiones definitivas, no recomendar desobedecer y ofrecer canalización al área jurídica. No afirmar que la transferencia ocurrió sin confirmación. Si existe peligro inmediato, recomendar ponerse a salvo y contactar emergencias.
