# Guía de consulta del catálogo · IMLUX

## Cuándo consultar

Usa `fetch_catalog_item_details` cuando el prospecto mencione un producto, modelo, código, familia o característica concreta.

## Parámetros

- `query`: texto concreto mencionado por el prospecto.
- `detail_level=overview`: respuesta comercial breve.
- `detail_level=metadata`: ficha o especificaciones solicitadas.
- `limit=1`: producto concreto.
- `limit` entre 2 y 5: consulta ambigua.

## Reglas

- No uses el catálogo para elegir una solución técnica por el prospecto.
- Si no hay coincidencias, pide un dato adicional o indica que el equipo debe confirmarlo.
- Si hay varias coincidencias, muestra solo las más relevantes y pregunta cuál desea revisar.
- No combines datos de productos diferentes.
- No inventes precio, disponibilidad, certificación, garantía o compatibilidad.
