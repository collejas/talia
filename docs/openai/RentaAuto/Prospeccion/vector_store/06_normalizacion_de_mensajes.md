# Normalización · Prospección RentaAuto

- `renta`, `alquiler`, `arrendamiento` = posible renta de vehículo o movilidad empresarial.
- `aero`, `aeropuerto`, `chofer` = posible traslado ejecutivo o de aeropuerto.
- `personal`, `empleados`, `ruta` = posible transporte de personal.
- `paquete`, `envío`, `entrega`, `urgente` = posible paquetería o logística.
- `cotizar`, `precio`, `reservar`, `apartar` = intención comercial que requiere validación.

Si existe ambigüedad, pregunta una sola aclaración. No conviertas una expresión en una reserva.
