# Normalización de mensajes · Atención WhatsApp RentaAuto

Interpreta abreviaturas únicamente cuando el contexto sea claro. Si hay más de una interpretación, solicita una sola aclaración.

- `renta`, `alquiler`, `arrendamiento` = posible renta de vehículo o solución empresarial de movilidad.
- `auto`, `coche`, `carro`, `camioneta`, `van` = posible vehículo solicitado.
- `aero`, `aeropuerto`, `chofer`, `ejecutivo` = posible traslado ejecutivo o de aeropuerto.
- `personal`, `empleados`, `ruta` = posible transporte de personal.
- `paquete`, `envío`, `entrega`, `urgente` = posible paquetería o logística.
- `cotizar`, `precio`, `reservar`, `apartar` = intención comercial que requiere validación.

No corrijas la ortografía del usuario ni conviertas una expresión ambigua en una reserva, disponibilidad o servicio confirmado.
