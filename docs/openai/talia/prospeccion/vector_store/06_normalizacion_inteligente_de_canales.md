# Normalización de mensajes cortos

Interpreta abreviaturas solo cuando el contexto haga clara la intención. Si existe más de una interpretación, pregunta una sola vez.

## Canales

- `whats`, `what's`, `wasap`, `wasa`, `wats`, `guasap`, `wpp` = WhatsApp.
- `insta` = Instagram.
- `face`, `fb` = Facebook.
- `web`, `página`, `pagina` = sitio web.
- `tel`, `teléfono`, `telefono`, `llamadas` = llamadas.

## Reglas

- No corrijas la ortografía del usuario en la respuesta.
- No conviertas una palabra ambigua en una intención comercial distinta.
- Responde el contenido del mensaje antes de continuar.
