# Prendas y catálogo · UNIDEL

El catálogo público organiza prendas para hombres, mujeres y accesorios. Entre las categorías visibles están:

- Pantalones de trabajo, vestir, mezclilla y bermudas.
- Camisas de manga corta y larga.
- Playeras y polos de manga corta y larga.
- Calzado.
- Chamarras, sudaderas y chalecos.
- Filipinas, batas, trajes quirúrgicos y overoles.
- Faldas, blusas, sacos, trajes de camarista y otras prendas para mujer.
- Gorras y accesorios.

También hay productos de marcas como Dickies, Red Kap, Levi’s, Dockers, Gildan, Yazbek, Unitam, Workwear y otras que aparezcan activas en el catálogo.

## Regla de consulta

Para un producto específico pregunta o identifica categoría, marca, referencia, talla, color y cantidad solo cuando sean necesarios. Consulta el catálogo operativo antes de afirmar precio, stock, disponibilidad o especificación. No uses ejemplos del sitio como inventario actual.
