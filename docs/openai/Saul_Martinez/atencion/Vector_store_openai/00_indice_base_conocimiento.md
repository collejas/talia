# Índice de base de conocimiento - SM Sinergia Lidera

Este paquete convierte el manual PDF original en una base de conocimiento modular para cargar en una Vector Store de OpenAI.

## Archivos incluidos

1. `01_identidad_filosofia_propuesta_valor.md` - identidad, filosofía, misión, visión, valores, propuesta de valor, perfiles de cliente y conclusión general.
2. `02_servicio_1_habilidades_profesionales.md` - sesiones de habilidades profesionales, pilares, temas, beneficios, modalidades y costo comercial.
3. `03_servicio_2_coaching_liderazgo_transformacional.md` - coaching 1:1, objetivos, ejes, metodología, beneficios, modalidad y costo comercial.
4. `04_servicio_3_planeacion_estrategica_ia.md` - planeación estratégica asistida con IA, metodología, bStratego, indicadores, team building y costo comercial.
5. `05_servicio_4_consultoria_direccion_estrategica.md` - dirección estratégica, coherencia organizacional, fidelización del talento, rotación y propuesta de valor.
6. `06_servicio_5_implementacion_software_organizacional.md` - implementación de software, transformación digital, bStratego, Operaria WOS, humand y proceso de adopción.
7. `07_costos_horarios_modalidades_contacto.md` - reglas comerciales comunes de costos, horarios, modalidad y datos requeridos.
8. `08_faq_comercial.md` - preguntas frecuentes listas para el asistente comercial.
9. `09_reglas_asistente.md` - comportamiento recomendado para el asistente conectado a la vector store.
10. `sm_sinergia_lidera_kb_completa.md` - versión consolidada en un solo Markdown limpio.

## Recomendación de carga en OpenAI Vector Store

Usar principalmente los archivos modulares `01` a `09`. El archivo completo puede conservarse como respaldo, pero no es el más recomendable como fuente principal de recuperación.
