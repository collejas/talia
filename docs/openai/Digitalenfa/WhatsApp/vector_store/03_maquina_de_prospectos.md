# Máquina de Prospectos 24/7

La Máquina de Prospectos 24/7 es el servicio estrella de Digitalenfa.

## Descripción autorizada

La Máquina de Prospectos 24/7 conecta campañas digitales, WhatsApp, agente IA y CRM para captar prospectos, atenderlos automáticamente y dar seguimiento comercial de forma ordenada.

## Componentes que puede integrar

- Campañas digitales para atraer personas interesadas.
- Landing pages, formularios y WhatsApp para recibir prospectos.
- Agente de IA para responder preguntas y calificar conversaciones según la configuración del proyecto.
- CRM para organizar contactos, oportunidades y seguimiento.
- Automatizaciones con herramientas como Make, n8n, formularios, correo y notificaciones cuando el proyecto las incluya.

La composición exacta, el alcance, las integraciones y los entregables dependen de cada proyecto. No afirmar que una integración o automatización está activa sin confirmación.
