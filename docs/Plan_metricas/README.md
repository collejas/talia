# Plan de métricas

Documento transversal para definir qué vista es responsable de cada métrica y
evitar duplicidad entre prospección, campañas y mapa de conversión.

## Documento maestro

- [Plan de consolidación de métricas](PLAN_CONSOLIDACION_METRICAS.md)

## Regla de lectura

El documento maestro define la semántica y la fuente de verdad. Los planes de
`mapa-de-conversion`, latencia, personas/contactos y listas de precios solo
mantienen referencias y restricciones específicas de su dominio.
