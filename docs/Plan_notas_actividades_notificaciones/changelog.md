# Changelog notas, actividades y notificaciones

## 2026-06-22

- Se creo el plan base para notas, actividades y notificaciones.
- Se amplio el flujo para cubrir supervision comercial desde la vista de oportunidades.
- Se definio que el supervisor pueda crear notas y actividades para un vendedor.
- Se establecio que la notificacion debe llegar al vendedor sin perder autoria del supervisor.
- Se agregaron backlog, backfill y mapa tecnico de implementacion.
